# 5. 単一ファイルモード

フォルダー全体ではなく Markdown ファイルを**1 つ**だけ読みたいこともあります。`.md` ファイルを直接開くと、SkimDown は**単一ファイルモード**に入ります。サイドバーが非表示になり、プレビューがウィンドウ全体を使います。

![サイドバーが非表示で、単一の Markdown ファイルが開いている状態](../images/single-file.png)

タイトルバーにはファイル名が表示されます。例: `first-steps.md — SkimDown`。

## 単一ファイルモードに入る方法

- **エクスプローラー** — `.md` / `.markdown` ファイルを右クリック → **Open with → SkimDown**（プログラムから開く → SkimDown。初回以降、SkimDown を `.md` ファイルの既定アプリに設定できます）。
- **コマンドライン** — `skimdown README.md`。
- **ドラッグ＆ドロップ** — 単一の `.md` ファイルを SkimDown のウィンドウにドラッグします。そのウィンドウにすでにフォルダーや別のファイルが開かれている場合、ドロップしたファイルは**新しい**ウィンドウで開きます。
- **複数ファイル** — エクスプローラーで複数の `.md` ファイルを選択し、**Open with → SkimDown** を選びます。各ファイルがそれぞれのウィンドウで開きます。

## 単一ファイルモードで異なる点

- **サイドバーが非表示**になり、**Toggle Sidebar**（サイドバーの切り替え、Ctrl+B）と **Move Sidebar**（サイドバーの移動）が無効になります。
- ファイルの**親フォルダーは引き続き監視される**ため、開いているファイルへの外部からの編集はプレビューにライブで反映されます。
- **相対 Markdown リンク**（例: `[next](./next.md)`）は、**新しい**単一ファイルウィンドウで開きます。
- フォルダー履歴は変更されません。**最近使ったフォルダー、最後のフォルダー、フォルダーごとの展開状態は更新されません。** エクスプローラーでファイルをダブルクリックしても、フォルダー履歴には影響しません。
- 保存済みのサイドバー表示状態は維持されます。後で **File → Open Folder…**（ファイル → フォルダーを開く）でフォルダーを開くと、サイドバーは設定したとおりにそのまま戻ります。

## フォルダー読みに戻る

任意のフォルダーを開く（**File → Open Folder…**、**Ctrl+O**、またはフォルダーをウィンドウにドラッグ）と、単一ファイルモードを抜けてサイドバーが戻ります。
