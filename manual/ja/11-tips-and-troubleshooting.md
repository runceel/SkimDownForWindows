# 11. ヒントとトラブルシューティング

## ライブリロード

SkimDown は開いているフォルダーを監視します。ディスク上で Markdown ファイルが**追加・削除・名前変更・変更**されると、サイドバーツリーとプレビューが自動的に更新されます。これは開いているファイルについては [単一ファイルモード](05-single-file-mode.md) でも動作します。手動でリロードする必要はありません。

## コンテンツはローカルに留まる

SkimDown は**ローカル専用**です。テレメトリーはなく、Markdown のテキストがマシンの外に送信されることはありません。レンダリング用のアセット（ハイライト、数式、図）はすべてアプリに同梱されているため、CDN やインターネット接続がなくてもプレビューは完全に**オフライン**で動作します。

## 設計上、ファイルごとに 1 ウィンドウ

SkimDown はユーザーごとに**単一プロセス**として動作します。エクスプローラーで Markdown ファイルを 2 回目以降にダブルクリックすると、そのアクティベーションは新しい起動ではなく、既存の SkimDown プロセスにルーティングされます。これにより、複数のウィンドウによって設定が上書きされるのを防ぎます。

## バージョンを確認する

**Help → About SkimDown**（ヘルプ → SkimDown について）を開くと、バージョンとプロジェクトのリンクが表示されます。

![バージョン 1.6.0 が表示された About SkimDown ダイアログ](../images/about.png)

About ダイアログには、バージョン（**1.6.0**）、短い説明、そして Windows 移植版リポジトリ、ドキュメントサイト、オリジナルの macOS プロジェクトへのリンクが表示されます。（Settings ダイアログと同様に、Windows のシステムテーマに従うため、Dark で表示されることがあります。）

## よくある質問

**SkimDown でファイルを編集できますか？**
いいえ。SkimDown は**読み取り専用**のビューアーであり、ファイルを変更することはありません。変更には通常のエディターを使用してください。SkimDown はライブリロードでその変更を表示します。

**フォルダーが空に見える / 「0 markdown files」と表示される。**
SkimDown は `.md` と `.markdown` ファイルのみを一覧表示し、隠しファイルや `.git`、`node_modules`、`.build`、`DerivedData` のようなノイズディレクトリはスキップします。それら以外に Markdown がないフォルダーは、空として読み込まれます。

**相対リンクが新しいウィンドウを開いた。**
これは単一ファイルモードの仕様です。相対 Markdown リンクは新しい単一ファイルウィンドウで開きます。フォルダーモードでは、サイドバーを使ってファイル間を移動してください。

**Light を選んだのに Settings や About のウィンドウが Dark になる。**
これらのダイアログは仕様として Windows のシステムテーマに従います。**プレビュー**だけが **View → Theme**（表示 → テーマ）で選んだテーマに従います。

**ウィンドウが前回の位置で再び開かなかった。**
[設定](09-settings.md) で **Restore previous window position and size on startup**（起動時に前回のウィンドウ位置とサイズを復元する）をオンにしてください。

**ターミナルで `skimdown` が認識されない。**
`skimdown` エイリアスはアプリのインストール時に登録されます。インストール後に**新しい**ターミナルを開くか、スタートメニューから一度アプリを起動してから、もう一度試してください。
