# 9. 設定

**View → Settings…**（表示 → 設定）を開くと、SkimDown の動作と外観の既定値を調整できます。必要な項目を変更したら **Save**（保存）をクリックします（破棄するには **Cancel**）。

![General と Appearance のオプションが表示された Settings ダイアログ](../images/settings.png)

> Settings ダイアログは Windows のシステムテーマに従うため、プレビューが Light に設定されていても Dark で表示されることがあります。

## General（一般）

| 設定 | 機能 |
| --- | --- |
| **Open containing folder when opening a single Markdown file**<br>（単一の Markdown ファイルを開くときに親フォルダーも開く） | **On** のとき、1 つの `.md` ファイルを開くと、単一ファイルモードを使わずにそのフォルダーもサイドバーに読み込みます。既定は **Off**。 |
| **Match case in Find by default**<br>（検索で既定として大文字・小文字を区別する） | **On** のとき、検索バーは大文字・小文字を区別する状態で始まります。既定は **Off**。 |
| **Restore previous window position and size on startup**<br>（起動時に前回のウィンドウ位置とサイズを復元する） | **On** のとき、SkimDown は前回と同じ位置・サイズで再び開きます。既定は **Off**。 |
| **Default zoom**<br>（既定のズーム） | 新しいウィンドウで使われるプレビューのズームレベル（1 = 100 %）。 |

## Appearance（外観）

| 設定 | 機能 |
| --- | --- |
| **Theme**（テーマ） | プレビューのテーマ: **System**、**Light**、**Dark**、またはカスタムテーマのいずれか。 |
| **Content width**（コンテンツ幅） | テキスト列の幅: **Standard (760 px)**、**Wide (960 px)**、**Extra Wide (1200 px)**、**Full Width**。 |
| **Sidebar position**（サイドバーの位置） | フォルダーツリーを **Left**（左）または **Right**（右）に配置します。 |
| **Show sidebar by default in folder mode**<br>（フォルダーモードで既定でサイドバーを表示する） | **On** のとき、フォルダーを開くたびにサイドバーが表示されます。既定は **On**。 |

これらと同じオプションは **View**（表示）メニューからも利用できます — [表示と外観](07-view-and-appearance.md) を参照してください。設定はユーザーごとに保存され、セッションをまたいで維持されます。
