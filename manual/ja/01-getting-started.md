# 1. はじめに

このページでは、SkimDown のインストール、初回起動、そして何かを開く前に表示される画面について説明します。

> ℹ️ アプリの UI は現在 **英語のみ**です。本マニュアルではメニュー名やボタン名を実際の画面どおり英語で表記し、必要に応じて（）内に日本語の意味を補足しています。

## SkimDown をインストールする

SkimDown はパッケージ化された Windows アプリです。次の 2 つの方法のいずれかでインストールします。

- **Microsoft Store** — ストアのページから直接インストールします:
  [**Microsoft Store の SkimDown**](https://apps.microsoft.com/detail/9nhtzmm0xmmf)（またはストアアプリで **SkimDown** を検索）を開き、**Get / Install**（入手 / インストール）を選びます。これが推奨の方法で、アプリは自動的に更新されます。
- **サイドロード（`.msixbundle`）** — 署名済みのサイドロードパッケージを受け取った場合は、証明書を一度だけインストールしてからパッケージを追加します:

  ```powershell
  certutil -addstore -f "TrustedPeople" .\devcert.cer   # 管理者として一度だけ実行
  Add-AppxPackage .\45014okazuki.SkimDown_<version>_sideload.msixbundle
  ```

> **注意:** Microsoft Store 版を一度インストールすると、同じアプリのサイドロード版をその場で上書き更新することはできません。Store 版をインストールする前に、サイドロード版をアンインストールしてください。

インストール後は `skimdown` というコマンドエイリアスが自動的に登録されるため、任意のターミナルからアプリを起動できます（[コンテンツを開く](02-opening-content.md) を参照）。

## 初回起動 — ウェルカム画面

フォルダーを指定せずに SkimDown を起動すると、ウェルカム画面が表示されます。サイドバーには **0 markdown files** と表示され、プレビュー領域に開始するための操作が表示されます。

![SkimDown のロゴと Open Folder ボタンが表示されたウェルカム画面](../images/empty-state.png)

ここから次のことができます。

- ウィンドウ中央の **Open Folder…**（フォルダーを開く）ボタンをクリックする、または
- **File → Open Folder…**（ファイル → フォルダーを開く、**Ctrl+O**）を使う、または
- エクスプローラーからフォルダーをウィンドウにドラッグする。

## 最初のフォルダー

フォルダーを開くと、SkimDown は見つかったすべての Markdown ファイルをサイドバーに一覧表示し、最初のファイル（または最後に表示したファイル）をプレビューにレンダリングします。

![SkimDown で開いたフォルダー。サイドバーツリーとレンダリングされた README が表示されている](../images/first-folder.png)

サイドバーのヘッダーには、フォルダー名と **6 markdown files** のような件数が表示されます。ツリー内の任意のファイルを選択して読みます。
