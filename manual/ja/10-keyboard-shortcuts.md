# 10. キーボードショートカット

SkimDown のキーボードショートカットの完全なリファレンスです。

## File（ファイル）

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+O** | Open Folder…（フォルダーを開く） |
| **Ctrl+W** | Close Window（ウィンドウを閉じる） |

## Edit & Find（編集と検索）

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+C** | Copy（選択したテキストをコピー） |
| **Ctrl+A** | Select All（すべて選択） |
| **Ctrl+F** | Find…（検索バーを開く） |
| **Ctrl+G** | Find Next（次を検索） |
| **Ctrl+Shift+G** | Find Previous（前を検索） |
| **Ctrl+E** | Use Selection for Find（選択範囲を検索に使用） |
| **Enter** / **Shift+Enter** | 次 / 前の一致（検索バーが開いているとき） |

## View & appearance（表示と外観）

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+B** | Toggle Sidebar（サイドバーの切り替え） |
| **Ctrl + `+`** | Zoom In（拡大） |
| **Ctrl + `-`** | Zoom Out（縮小） |
| **Ctrl + `0`** | Actual Size（実際のサイズ。ズームをリセット） |
| **Ctrl + `]`** | コンテンツ列を広く |
| **Ctrl + `[`** | コンテンツ列を狭く |
| **Ctrl + マウスホイール** | スムーズズーム |
| **タッチパッドのピンチ** | スムーズズーム |

## Window（ウィンドウ）

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+N** | New Window（新しいウィンドウ） |
| **Ctrl+M** | Minimize（最小化） |

> ズームはセッションをまたいで記憶されます（50〜300 % に制限）。マウス、メニュー、ドラッグ＆ドロップでの操作については、[表示と外観](07-view-and-appearance.md) と [コンテンツを開く](02-opening-content.md) を参照してください。
