# 3. フォルダービューとナビゲーション

フォルダーを開くと、SkimDown は 2 つの領域を表示します。片側に**サイドバーツリー**、もう片側に**プレビュー**です。

![SkimDown のウィンドウ構成: タイトルバー、メニューバー、サイドバーツリー、プレビュー](../images/main-window.png)

## ウィンドウの構成

1. **タイトルバー** — フォルダー名とアプリ名が表示されます。例: `SkimDown Demo — SkimDown`。
2. **メニューバー** — **File**、**Edit**、**View**、**Window**、**Help**（ファイル、編集、表示、ウィンドウ、ヘルプ）。
3. **サイドバーヘッダー** — フォルダー名と、**6 markdown files** のような件数。
4. **サイドバーツリー** — フォルダー内のすべての Markdown ファイルを、サブフォルダーごとに整理して表示します。
5. **プレビュー** — 選択したファイルをレンダリングした Markdown。

## サイドバーツリー

SkimDown はフォルダーを**再帰的に**スキャンして `.md` と `.markdown` ファイルを探し、フォルダーを先に、大文字・小文字を区別せずに並べ替えて表示します。サブフォルダー（上の例の `Getting Started`、`Guides`、`Reference` など）内のファイルは、それぞれのフォルダーの下にグループ化されます。

隠しファイルやノイズとなるディレクトリは自動的に除外されます。`.git`、`node_modules`、`.build`、`DerivedData` などのフォルダーはツリーに表示されません。

### ナビゲーション

- **ファイルをクリック**すると、プレビューにレンダリングされます。
- **フォルダー**（またはその山形アイコン）をクリックすると、展開または折りたたまれます。
- **Ctrl+B** を押すと、サイドバーの表示/非表示を切り替えられます（**View → Toggle Sidebar**、表示 → サイドバーの切り替え）。

SkimDown は**フォルダーごとに展開状態を記憶**し、最後に選択していたファイルも覚えているため、フォルダーを再び開くと前回の状態に戻ります。

## ライブ更新

ツリーとプレビューは常にディスクの内容と同期します。フォルダーを開いている間に Markdown ファイルが**追加・削除・名前変更・更新**されると、SkimDown は自動的に更新します。手動でのリロードは不要です。

## サイドバーの移動と非表示

サイドバーは**左**または**右**に配置するか、完全に非表示にできます。[表示と外観](07-view-and-appearance.md#サイドバー) を参照してください。
