# 6. 検索とコピー

SkimDown は読み取り専用ですが、ドキュメント内を検索したり、テキストやファイルパスをコピーしたりできます。

## 現在のファイル内のテキストを検索する

**Ctrl+F**（または **Edit → Find…**、編集 → 検索）を押すと、ウィンドウ上部にドキュメント内検索バーが開きます。単語を入力すると、SkimDown は一致するすべての箇所をハイライトし、**1 / 1** のようなカウンターを表示します。

![「rendering」を検索している検索バー。一致箇所がハイライトされ、1/1 のカウンターが表示されている](../images/find-highlight.png)

検索バーのコントロール（左から右）:

- **検索ボックス** — クエリを入力します。中の **✕** でテキストをクリアします。
- **Aa** — **大文字・小文字の区別**（match case）のオン/オフを切り替えます。
- **‹** / **›** — 前 / 次の一致へ移動します（**Ctrl+Shift+G** / **Ctrl+G**）。
- **1 / 1** — 現在の一致と一致の総数。
- **✕** — 検索バーを閉じます。

**Enter** / **Shift+Enter** でも一致箇所間を移動できます。

### 現在の選択範囲で検索する

プレビューでテキストを選択してから、**Edit → Use Selection for Find**（編集 → 選択範囲を検索に使用、**Ctrl+E**）を選ぶと、その文字列をそのまま検索します。

## コピーと選択

![Edit メニュー: Copy、Select All、Find、Find Next、Find Previous、Use Selection for Find](../images/menu-edit.png)

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **Copy** | Ctrl+C | プレビューで選択したテキストをコピーします。 |
| **Select All** | Ctrl+A | 現在のドキュメントのすべてのテキストを選択します。 |
| **Find…** | Ctrl+F | ドキュメント内検索バーを開きます。 |
| **Find Next** | Ctrl+G | 次の一致へ移動します。 |
| **Find Previous** | Ctrl+Shift+G | 前の一致へ移動します。 |
| **Use Selection for Find** | Ctrl+E | 現在選択中のテキストを検索します。 |

## ファイルのパスをコピーする / 表示する

**File**（ファイル）メニューから:

- **Copy File Path** — 選択中のファイルのフルパスをクリップボードにコピーします。
- **Reveal in File Explorer** — そのファイル（またはフォルダー）を選択した状態でエクスプローラーを開きます。
