# SkimDown for Windows — ユーザーマニュアル

> 🌐 **Languages:** [English](../README.md) | **日本語**
>
> ℹ️ アプリの UI は現在 **英語のみ**です。本マニュアルではメニュー名やボタン名を実際の画面どおり英語で表記し、必要に応じて（）内に日本語の意味を補足しています。

**SkimDown for Windows** は、**読み取り専用**の Markdown フォルダービューアーです。フォルダーを指定すると、その中の Markdown ファイルだけをサイドバーのツリーに表示し、選んだファイルをプレビューに表示します。編集用の UI はなく、ファイルを誤って変更することはありません。インターネット接続も不要です。

![SkimDown のメインウィンドウ: メニューバー、サイドバーツリー、レンダリングされたプレビュー](../images/main-window.png)

> **対象バージョン 1.6.0。** バージョンは **Help → About SkimDown**（SkimDown について）で確認できます。

> 📦 **SkimDown の入手:** [**Microsoft Store**](https://apps.microsoft.com/detail/9nhtzmm0xmmf) から入手できます。
> インストールの詳細は [はじめに](01-getting-started.md) を参照してください。

## SkimDown の用途

- AI エージェント、開発ツール、チームが生成した Markdown **フォルダー**を読む。
- エディターを使わずに、ドキュメント・変更履歴・メモに目を通す。
- リッチな Markdown（コードハイライト、表、タスクリスト、GitHub 形式のアラート、数式、Mermaid 図）を完全に**オフライン**で表示する。

SkimDown は**ファイルを編集しません。** 見つけた Markdown を読み取ってレンダリングするだけです。

## ひと目でわかる使い方

- **フォルダーを開く:** **File → Open Folder…**（フォルダーを開く、**Ctrl+O**）、ドラッグ＆ドロップ、または任意のターミナルから `skimdown .`。
- **ファイルを選ぶ:** サイドバーで選択するとレンダリングされます。
- **テキストを検索する:** **Ctrl+F** で現在のファイル内を検索。
- **テーマを切り替える:** **View → Theme**（表示 → テーマ。System / Light / Dark）。
- すべては**あなたのマシン上で完結**します — テレメトリーはなく、Markdown が PC の外に出ることはありません。
