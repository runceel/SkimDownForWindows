# SkimDown for Windows — User Manual

> 🌐 **Languages:** **English** | [日本語](ja/README.md)

**SkimDown for Windows** is a **read‑only** Markdown folder reader. Point it at a folder
and it shows only the Markdown files in a sidebar tree, then renders the file you select in the
preview. It has no editing UI, so files are never changed accidentally, and it requires no internet
connection.

![The SkimDown main window: menu bar, sidebar tree, and rendered preview](images/main-window.png)

> **Applies to version 1.6.0.** You can confirm your version with **Help → About SkimDown**.

> 📦 **Get SkimDown** from the [**Microsoft Store**](https://apps.microsoft.com/detail/9nhtzmm0xmmf).
> See [Getting started](01-getting-started.md) for installation details.

## What SkimDown is for

- Reading Markdown **folders** generated by AI agents, developer tools, and teams.
- Reviewing docs, changelogs, and notes without using an editor.
- Viewing rich Markdown — code highlighting, tables, task lists, GitHub‑style alerts, math, and
  Mermaid diagrams — fully **offline**.

SkimDown **never edits your files.** It only reads and renders the Markdown it finds.

## At a glance

- **Open a folder** with **File → Open Folder…** (**Ctrl+O**), drag‑and‑drop, or `skimdown .`
  from any terminal.
- **Pick a file** in the sidebar to render it.
- **Find text** in the current file with **Ctrl+F**.
- **Switch theme** (System / Light / Dark) from **View → Theme**.
- Everything stays **on your machine** — no telemetry, no Markdown leaves your PC.
