# 10. Keyboard shortcuts

A complete reference of SkimDown's keyboard shortcuts.

## File

| Shortcut | Action |
| --- | --- |
| **Ctrl+O** | Open Folder… |
| **Ctrl+W** | Close Window |

## Edit & Find

| Shortcut | Action |
| --- | --- |
| **Ctrl+C** | Copy selected text |
| **Ctrl+A** | Select All |
| **Ctrl+F** | Find… (open the search bar) |
| **Ctrl+G** | Find Next |
| **Ctrl+Shift+G** | Find Previous |
| **Ctrl+E** | Use Selection for Find |
| **Enter** / **Shift+Enter** | Next / previous match (while the Find bar is open) |

## View & appearance

| Shortcut | Action |
| --- | --- |
| **Ctrl+B** | Toggle Sidebar |
| **Ctrl + `+`** | Zoom In |
| **Ctrl + `-`** | Zoom Out |
| **Ctrl + `0`** | Actual Size (reset zoom) |
| **Ctrl + `]`** | Wider content column |
| **Ctrl + `[`** | Narrower content column |
| **Ctrl + mouse wheel** | Smooth zoom |
| **Touchpad pinch** | Smooth zoom |

## Window

| Shortcut | Action |
| --- | --- |
| **Ctrl+N** | New Window |
| **Ctrl+M** | Minimize |

> Zoom is remembered between sessions (clamped to 50–300 %). For mouse, menu, and drag‑and‑drop
> equivalents, see [View & appearance](07-view-and-appearance.md) and
> [Opening content](02-opening-content.md).
